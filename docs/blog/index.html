Notes from building an honest code reviewer

Every experiment we ran on our own reviewer, including the ones where the result was worse than the claim. The leaked answer key, the control group that failed, the benchmark that turned out to have been run on the wrong model — all of it is here, in the order it happened.

中文读者：代码不出内网：企业内网部署 AI 代码审查的完整方案

  1. 2026-11 · experiment · EN

    Our AI reviewer caught 10 out of 10 known vulnerabilities. Ignore that number.

    Ten reverted CVE fixes, no hints, ten hits — and four reasons why the score measures almost nothing about real pull requests.
  2. 2026-11 · correction · EN

    Does the PR description leak the answer key?

    A reader asked whether the benchmark was measuring reading comprehension. We audited the prompt path, found the published runs had not stripped test hunks as claimed, then re-ran the suite three ways.
  3. 2026-11 · control group · EN

    We ran the control a reader asked for. It also turned out we had benchmarked the wrong model.

    Ten ordinary commits reverted alongside the ten CVE fixes: seven stayed silent, three produced confident findings about real but non-security bugs. Re-reading the logs showed every original run had used a rate-limit fallback model.
  4. 2026-11 · experiment · EN

    Same reviewer, three models: is the noise sampling or model choice?

    With fallback disabled, every model missed a different case. Cross-model spread exceeded cross-pass spread on a single model — and the fail-closed gate withheld 6 of 10 verdicts on the free tier.
  5. 2026-11 · noise measurement · EN

    We ran our AI reviewer on 20 ordinary merged commits. It commented 4 times.

    Nothing planted, real commits from psf/requests. We read all four comments and graded them by hand — including the one that was wrong.
  6. 2026-11 · postmortem · EN

    The code that ran was not the code I read

    Four agents timed out at 90 seconds each. The network was fine. The bug was a dict.get default that turned a version mismatch into a connect timeout.
