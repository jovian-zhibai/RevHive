Privacy Policy

Last updated: 2026-09-08 · Applies to the RevHive hosted GitHub App and this website.

The short version

  • ✓Self-hosting (CLI or server)? We receive nothing. Your code, diffs and API keys never leave your infrastructure.
  • ✓Hosted GitHub App? We receive only what GitHub sends to complete a review: PR diffs and metadata for repos you install the App on. We do not train models on your code.
  • ✕We never sell, share, or monetize your code or metadata.

1. What we collect — hosted GitHub App

  • Repository content in scope: pull request diffs, changed-file contents, PR titles/descriptions — strictly for repos where you install the App, strictly to perform a review.
  • Account identifiers: GitHub installation ID, repository names, and the GitHub user ID of the installer (for billing and support).
  • LLM provider data: by default, review payloads are sent to the LLM backend configured for your account (BYOK — your key, your chosen provider: DeepSeek, MiMo, Qwen, GLM, Kimi, etc.). Provider handling is governed by that provider's policy. You can point RevHive at a provider you fully control.
  • Operational logs: request timestamps, repo name, review outcome. Logs retain diffs for 30 days (for debugging), then purge.

2. What we collect — website & licensing

  • Email you send us for licensing/support — kept for the business relationship only.
  • Billing metadata from the payment processor (plan, status, invoice ID). Card numbers never touch our servers — payments are handled by the processor.

3. What we never do

  • No training any model on your code — ours or anyone else's.
  • No selling or sharing code, diffs, or metadata with third parties (except the LLM provider you configure, to perform the review you requested).
  • No reading repos outside the App installation scope.

4. Data residency

Hosted service infrastructure location and sub-processors will be listed here before general availability. If your compliance requires code to remain in a specific jurisdiction (e.g., PRC), the Self-Host License keeps all data inside your own network — that is its primary purpose.

5. Your rights

Email souljian67@gmail.com to request export or deletion of your account data, or to uninstall the App (which immediately stops all new data flow; stored diffs purge within 30 days).

6. Changes

Material changes will be announced in the repo and via the App before taking effect. This is a draft — the version in force at the time of processing governs.
